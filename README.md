# Week-day-1-Tasks

# Week 2 Day 1 JavaScript Assignment

This project contains JavaScript exercises covering functions,
strings, arrays and objects.

## Task 1 - Classic Functions

- FizzBuzz
- Reverse String
- Palindrome Checker
- Find Largest Number
- Count Vowels

## Task 2 - Kenyan County Object

Created county objects and functions to:

- Display county information
- Format population
- Display bordering counties

## Task 3 - Matatu Route System

Created 10 matatu routes and functions to:

- Find the cheapest route
- Find routes through a stop
- Calculate total journey fare

## Technologies Used

- JavaScript
- Node.js
- Git
- GitHub

## Running the Project

Run:

node task1-index.js

node task2-county.js and routes
